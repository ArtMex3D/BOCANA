Plan Detallado de Refactorización: Módulo Traspasos Inteligente v2.1 (Ajustado)

Filosofía Central:

Sugerencia Inteligente: La app sugiere proactivamente (basado en stockIdealC04 [mínimo], stockMaximoC04 [óptimo], liquidación de lotes por agotarse, lógica Rector/Regido por fechas), pero siempre es solo una sugerencia.

Control Manual Total: El usuario puede anular cualquier sugerencia (cantidad, lotes FIFO, lotes por liquidar, lotes por categoría) en cualquier etapa (Planificación o Confirmación Final).

Claridad Granel vs. Fijo: Se diferencia visualmente y funcionalmente el manejo de productos por KG (Granel) y por Unidades (Fijos) en la planificación, con campos específicos para el PDF en Granel.

Liberación de Lotes Flexible: Los lotes se reservan (estadoTraspaso) durante la planificación para evitar conflictos. En la pantalla de Confirmación Final, el diálogo de selección de lotes debe mostrar todos los lotes disponibles (libres + los reservados por ese plan) para permitir la edición final. La confirmación o cancelación libera correctamente los lotes (quitando estadoTraspaso).

Fase 1: Refactorización Inteligente - ViewModel Planificación (PlanificarTraspasoViewModel.kt)

Reescritura Lógica de Sugerencia (Función Principal generarSugerenciasInteligentes):

Orden Inicial: Obtener productos ordenados por prioridadDesabasto (descendente) y luego ordenTraspaso (ascendente).

Iteración por Producto:

Identificar Tipo: Determinar si es Fijo, Granel, Rector, Regido.

Necesidad Base: necesidadKg = max(0.0, stockIdealC04 - stockCongelador04) (Lo mínimo que falta).

Espacio Disponible: espacioHastaMaximoKg = max(0.0, stockMaximoC04 - stockCongelador04).

Sugerencia Base (FIFO):

Fijo: Calcular unidadesNecesariasBase = ceil(necesidadKg / pesoUnidad). Desglosar lotes libres FIFO para cubrir unidadesNecesariasBase. Calcular kgSugeridosBase a partir de las unidades tomadas.

Granel: kgSugeridosBase = min(necesidadKg, stockDisponibleMatriz). Desglosar lotes libres FIFO para cubrir kgSugeridosBase.

Segunda Pasada (Liquidación Lotes por Agotar - Icono 💡):

Buscar lotes libres del mismo producto en Matriz casi agotados (ej., currentQuantity < umbralLiquidacionKg o < 1.5 * pesoUnidad si es fijo).

kgFaltantesParaMaximo = espacioHastaMaximoKg - kgSugeridosBase.

Para cada lote por liquidar encontrado:

kgParaLiquidar = lote.currentQuantity.

Si kgParaLiquidar <= kgFaltantesParaMaximo:

Añadir este lote al desglose (lotesParaTraspaso).

Incrementar kgSugeridosTotal (kgSugeridosBase += kgParaLiquidar).

Marcar el TraspasoSugerenciaItem con isSugerenciaLiquidacion = true.

Actualizar kgFaltantesParaMaximo.

Si no, pasar al siguiente lote por liquidar (no hay espacio suficiente).

Tercera Pasada (Lógica Rector/Regido):

Identificar meses/años de los lotes sugeridos para Rectores.

Para productos Regidos sin sugerencia (kgSugeridosTotal == 0.0):

Buscar lotes libres que coincidan en mes/año con su Rector.

Si se encuentran, generar una sugerencia completa para el Regido (Necesidad Base + Liquidación) usando solo los lotes coincidentes.

Finalizar Item: Calcular impactoStockMatriz, inicializar campos PDF Granel (cantidadEditadaUnidades = 0, unidadDeEmpaqueEditada = "Kg"), crear TraspasoSugerenciaItem.

Manejo de Ediciones Manuales:

Actualización Rector -> Regido: Implementar la función que re-ejecuta la "Tercera Pasada" cuando cambian los lotes de un Rector.

recalcularSugerenciaPorUnidades: Para Fijos.

recalcularSugerenciaPorKg (Nueva): Para Granel (si se habilita edición directa de KG).

actualizarLotesManualmente / actualizarPorDesglloseManual: Recalcular sugerenciaKg y impactoStockMatriz basados en la selección/desglose manual. Poner lotesSeleccionadosManualmente = true en el TraspasoSugerenciaItem.
